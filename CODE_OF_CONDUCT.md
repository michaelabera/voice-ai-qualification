# Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for
everyone, regardless of background or identity.

## Standards

Examples of positive behavior: being respectful, giving and accepting
constructive feedback, and focusing on what's best for the community.

Unacceptable behavior includes harassment, personal attacks, and publishing
others' private information without permission.

## Enforcement

Project maintainers are responsible for clarifying standards and may remove
contributions or contributors that violate this code.

This Code of Conduct is adapted from the Contributor Covenant, version 2.1.
